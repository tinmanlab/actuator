03 / Learn by changing one thing

Engineering documentation ↗
LAB 01 / 30 SECONDS

Follow a target

Choose Track a target. Move the target to 0.8 rad. Read the error and compare the plant-state line with the reference. Pause and advance one millisecond.

LAB 02 / DISTURBANCE

Feel the stiffness

Choose Reject a push. A 4 N·m pulse lasts 120 ms at t = 0.7 s. Then set a constant 2 N·m load. With Kp = 30, expect about 0.067 rad of static displacement.

LAB 03 / CONTACT

Push against a stop

The target is 0.85 rad but the stop is at 0.60 rad. Watch current and torque grow while the angle stops. Compliance permits small penetration; this is not a rigid clamp.

LAB 04 / PROTECTION

Stop driving, not physics

Trip the driver. Gates switch off, but stored energy and inertia remain. The fault is latched. Reset creates a new virtual experiment; it is not a hardware reset procedure.

Build, extend, or run the full MuJoCo viewer locally

The simulation library is C++17. The web UI uses Three.js only for rendering. No cloud inference, backend, or API key is required.

git clone https://github.com/tinmanlab/actuator.git
cd actuator
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
python -m pip install -r examples/mujoco/requirements.txt
python examples/mujoco/run.py --case disturbance --live \
  --output results/my-first-run

Use a new output directory for each run. Linux uses python; macOS passive viewer may require mjpython. Full quickstart and troubleshooting ↗

Know the boundary. This is a synthetic software-in-the-loop lab, not a validated commercial actuator or PCB. Browser: averaged inverter + native 1-axis mechanics. Films: actual MuJoCo. Hardware calibration, STM32 timing, and safety certification are not claimed.
